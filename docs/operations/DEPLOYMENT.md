# استقرار
ResearchHub روی Vercel قابل استقرار است.
قبل از اعلام آماده بودن: `npm run typecheck`، `npm run build` و در صورت وجود ESLint config، `npm run lint`.
همچنین Login، نقش‌ها، APIهای اصلی و لاگ deployment بررسی شوند.
هر تغییر مهم Production باید اثر، ریسک، Backup، Rollback، Verification و تأیید لازم را مشخص کند.
