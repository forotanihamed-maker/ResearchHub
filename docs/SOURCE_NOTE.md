# یادداشت منبع
این مجموعه بر اساس مستندات موجود ResearchHub و تصمیم‌های ثبت‌شده در روند توسعه بازنویسی شده است.
متن‌های تکراری حذف و محصول، وضعیت فعلی، فنی، کسب‌وکار و Developer AI از هم جدا شده‌اند.
قابلیت‌های آینده به‌عنوان قابلیت فعلی معرفی نشده‌اند.
اگر سند با Repository واقعی اختلاف داشت، Repository و تست جاری مبنا هستند و سند باید اصلاح شود.
