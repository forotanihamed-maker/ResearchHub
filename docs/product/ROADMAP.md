# ResearchHub — Roadmap

## Near Term

هدف نزدیک: آماده‌سازی محصول برای **Pilot-ready state** و ورود به مسیر پیش‌رشد مرکز رشد.

اولویت‌ها:

1. تثبیت مستندات
2. رفع اختلاف سیاست محصول و implementation
3. تثبیت امنیت و permission model
4. تثبیت file storage
5. تست end-to-end چرخه پروژه
6. آماده‌سازی نسخه قابل ارائه برای Pilot

## بعد از Pilot

- اصلاح workflow بر اساس داده واقعی
- بهبود faculty dashboard
- گزارش‌گیری مدیریتی
- workflow اختصاصی انواع پروژه
- بهبود discovery و matching

## Future / Long Term

- Cross-faculty collaboration
- Industry liaison integration
- Research-to-industry workflow
- Advanced analytics
- AI-assisted matching
- Project-to-paper workflows

هیچ‌یک از موارد Future نباید به‌عنوان قابلیت موجود معرفی شوند.
