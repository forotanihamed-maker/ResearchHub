# فضای اجرای پروژه
هدف: تبدیل پروژه از یک رکورد اطلاعاتی به محیط قابل پیگیری برای اجرا.
## Tasks
واحد اجرایی پروژه با عنوان، توضیح، ایجادکننده، مسئول، وضعیت، اولویت، تاریخ شروع و مهلت.
وضعیت‌ها: انجام‌نشده، در حال انجام، انجام‌شده. عقب‌افتادگی محاسبه می‌شود و وضعیت ذخیره‌شده نیست.
## Milestones
نقاط معنادار مسیر پروژه با عنوان، توضیح، وضعیت و زمان رسیدن. `reachedAt` توسط سرور ثبت می‌شود.
## Activity
تاریخچه رویدادهای Task و Milestone: ایجاد، تغییر وضعیت، حذف، تغییر مسئول، ایجاد/رسیدن/برگشت/حذف Milestone.
## Overview
تعداد و وضعیت Taskها، پیشرفت، مهلت، آخرین Milestone و فعالیت‌های اخیر.
## Progress
پیشرفت Task = انجام‌شده/کل. پیشرفت Milestone = رسیده/کل. Progress به‌صورت بخش جدا و تکراری ساخته نمی‌شود و در Overview قرار دارد.
## اصل
این بخش نباید به ابزار مدیریت پروژه عمومی و سنگین تبدیل شود.
