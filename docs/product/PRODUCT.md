# ResearchHub — Product Definition

## 1. Product Summary

ResearchHub یک زیرساخت دانشگاهی برای **مدیریت چرخه پروژه‌های دانشکده** است؛ از ایجاد پروژه و تشکیل تیم تا اجرای فعالیت‌ها، ارتباط، فایل‌ها، مستندات و آرشیو.

مدل اصلی محصول:

```text
Faculty
  └── Projects
       ├── Professor / Student Creator
       ├── Members
       ├── Tasks
       ├── Milestones
       ├── Activity History
       ├── Chat
       ├── Files & Documents
       └── Project Status
```

## 2. Customer vs User

### Customer
- دانشگاه
- دانشکده
- مرکز پژوهشی

### Users
- Student
- Professor
- Faculty Administrator

استاد و دانشجو کاربر محصول هستند؛ مشتری اصلی در مدل فعلی دانشکده/سازمان دانشگاهی است.

## 3. Core Value

ارزش محوری ResearchHub، یکپارچه‌کردن چرخه پروژه در یک محیط واحد است:

**ایجاد → جذب عضو → تشکیل تیم → اجرای پروژه → مدیریت فعالیت‌ها → مستندسازی → پایان → آرشیو**

## 4. Current Project Types

- Thesis
- Internship
- Course
- Research

نوع پروژه در کد فعلی ثبت می‌شود، اما workflow اختصاصی برای هر نوع هنوز وجود ندارد.

## 5. Main User Value

### Student
- کشف پروژه‌های قابل مشاهده
- درخواست عضویت
- همکاری در پروژه
- مدیریت فعالیت‌های مربوط به خود
- دسترسی به سابقه پروژه‌ها و مستندات

### Professor
- ایجاد پروژه
- جذب و مدیریت اعضا
- مدیریت فعالیت‌های پروژه
- فایل و مستندات
- مشاهده سابقه و وضعیت اجرای پروژه

### Faculty Admin
- مشاهده شاخص‌ها و پروژه‌های مشمول scope مدیریتی
- مشاهده وضعیت پروژه‌ها
- مدیریت بخشی از اطلاعات استادان/گروه‌ها
- ارسال پیام مستقیم به استادان

## 6. Product Boundary

ResearchHub در نسخه فعلی ابزار مدیریت و اجرای پروژه است؛ جایگزین قراردادهای رسمی دانشگاه، سیستم مالی، سامانه‌های رسمی تصویب پژوهش یا دفتر ارتباط با صنعت نیست.
