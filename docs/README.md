# ResearchHub — مستندات رسمی
این مجموعه مرجع یکپارچه مستندات ResearchHub است. اسناد به پنج حوزه محصول، فنی، عملیات، کسب‌وکار و Developer AI تقسیم شده‌اند.
ResearchHub در مرحله MVP/اعتبارسنجی است و تمرکز فعلی آن بر مدیریت و اجرای پروژه‌های دانشگاهی، تیم پروژه و نظارت عملیاتی است.
قاعده اصلی: قابلیت فعلی، وضعیت واقعی کد است؛ ایده‌های آینده نباید به‌عنوان قابلیت موجود معرفی شوند.
