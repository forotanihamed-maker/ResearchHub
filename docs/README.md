# ResearchHub — مستندات رسمی
این مجموعه مرجع یکپارچه مستندات ResearchHub است. اسناد به پنج حوزه محصول، فنی، عملیات، کسب‌وکار و Developer AI تقسیم شده‌اند.
ResearchHub در مرحله MVP/اعتبارسنجی است و تمرکز فعلی آن بر مدیریت و اجرای پروژه‌های دانشگاهی، تیم پروژه و نظارت عملیاتی است.
قاعده اصلی: قابلیت فعلی، وضعیت واقعی کد است؛ ایده‌های آینده نباید به‌عنوان قابلیت موجود معرفی شوند.


## مرجع و اعتبارسنجی
مرجع اصلی اسناد این پوشه است. بستهٔ `ResearchHub_AI_Developer_V1/` برای انتقال context به عامل کدنویسی است و باید با این اسناد همگام بماند. پوشهٔ `ai-assistant/` راهنمای عملیاتی و playbook است، نه پیاده‌سازی سرویس دستیار AI. گزارش ممیزی ایستای ZIP در `REPOSITORY_AUDIT_2026-09-26.md` آمده است؛ آزمون‌های typecheck/build و اتصال به سرویس‌های واقعی در آن اجرا نشده‌اند.
