# Pilot
هدف Pilot اثبات ارزش در یک پروژه واقعی است، نه صرفاً نمایش نرم‌افزار.
سناریو:
یک استاد حامی → یک پروژه واقعی → تشکیل تیم → استفاده واقعی → اندازه‌گیری → بازخورد → اصلاح محصول و مدل تجاری.
شاخص‌ها: استفاده واقعی از Task/Milestone، تکمیل کارها، استفاده استاد از Overview، تمرکز گفتگو/فایل و تغییر مشکل قبل/بعد.
نیازهای مطرح‌شده برای مرکز رشد: معرفی استاد/دانشکده Pilot، حمایت Pilot، فضای کاری، منتورینگ تجاری و کمک ورود به بازار.
خروجی: Pilot قابل اندازه‌گیری، بازخورد مستند و مدل تجاری معتبرتر.
